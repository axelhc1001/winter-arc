# Winter Arc ❄️

Registro diario y tabla de posiciones del Winter Arc (1 oct – 23 dic 2026).

- `index.html`: la página completa.
- `config.js`: URL y llave pública de Supabase.
- `app.js`, `style.css`: la app (instalable, con `sw.js` y `manifest.webmanifest`).
- `supabase.sql` y luego `supabase_v2.sql`: tablas y funciones (SQL Editor de Supabase).
- `push/` + `.github/workflows/recordatorio.yml`: aviso de las 10 pm (secretos en GitHub).

Cuando termine el reto: borrar este repo y el proyecto de Supabase.
