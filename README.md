# Winter Arc ❄️

Registro diario y tabla de posiciones del Winter Arc (1 oct – 31 dic 2026).

- `index.html`: la página completa.
- `config.js`: URL y llave pública de Supabase.
- `supabase.sql`: tablas y funciones (pegar en el SQL Editor de Supabase).

Cuando termine el reto: borrar este repo y el proyecto de Supabase.
